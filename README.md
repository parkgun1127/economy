## 📌 프로젝트 소개

이 프로젝트는 **한국 사교육 상업화의 구조적 문제점**을 데이터 기반으로 분석한
인터랙티브 보고서 웹사이트입니다.

통계청·교육부의 공식 데이터를 활용하여 사교육 산업이 어떻게
거대한 상업적 생태계로 성장했는지를 시각화하고 분석합니다.

### 🎯 핵심 분석 내용

| 분석 항목 | 주요 내용 |
|-----------|-----------|
| 📊 학교급별 사교육비 | 초·중·고 단계별 사교육비 총액 및 추이 |
| 🎯 성적 구간별 참여율 | 성적과 사교육 참여의 상관관계 |
| 🏗️ 산업화 구조 | 공급자·수요자·자본의 3축 생태계 분석 |
| 💰 수익 메커니즘 | 가격 전략·심리 마케팅·스타 강사 경제학 |
| ⚠️ 사회적 영향 | 교육 불평등·학력 세습·저출생 연관성 |
| ✅ 결론·제언 | 정책 대안 및 교육 개혁 시사점 |

## ⚙️ 설치 및 실행 방법

### 1️⃣ 저장소 클론

```bash
git clone https://github.com/본인계정/사교육-산업화-보고서.git
cd 사교육-산업화-보고서
```

### 2️⃣ 가상환경 생성 (권장)

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python -m venv venv
source venv/bin/activate
```

### 3️⃣ 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 4️⃣ 데이터 파일 배치

```
data/ 폴더 안에 아래 두 파일을 넣어주세요:

✅ 학교급별_사교육비_총액_20260610132639.csv
✅ 학생_성적_구간별_사교육_참여율.csv
```

### 5️⃣ 앱 실행

```bash
streamlit run app.py
```

브라우저에서 자동으로 `http://localhost:8501` 이 열립니다.

## 🔍 주요 분석 결과 요약

### 1. 사교육 시장 현황
- **2023년 사교육 총 시장 규모: 26조 원** (역대 최고)
- 학생 1인당 월평균 지출: **43.4만 원**
- 초·중·고 사교육 참여율: **78.5%**

### 2. 소득 계층별 격차
```
소득 상위 20%  →  월 80.2만 원  (참여율 92.1%)
소득 하위 20%  →  월 11.4만 원  (참여율 35.2%)
                    ↑
               약 7배 격차
```

### 3. 산업화의 핵심 구조
```
[불안 마케팅] → [수요 창출] → [고가 수강료]
      ↑                              ↓
[재등록 유도] ← [성과 피드백] ← [학습 소비]
```

### 4. 핵심 문제점
- 📉 "교육으로 계층 이동 가능" 인식: 1990년 68% → 2023년 **30%**로 급락
- 👶 사교육비 증가와 합계출산율 감소의 **역상관 관계** 확인
- 🏢 상위 5개 기업 시장점유율: 2015년 28% → 2023년 **51%**로 독점화
